# Stitch design export (reference only)

The client's original Google Stitch design for Serendiva. Each folder is one screen: `code.html` (the Stitch
Tailwind markup the website was ported from, class for class) and `screen.png` (the rendered mock-up).
`serendiva_luxury_expeditionary/DESIGN.md` describes the design language (colours, type, spacing, tone).
The folder `whatsapp_image_2026_10_04_at_11.30.51.jpeg/` holds the original logo as `screen.png` (the site uses the
same file as `public/brand/serendiva-logo.png`).
